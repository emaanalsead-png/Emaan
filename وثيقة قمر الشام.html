🌙 1. نظرة عامة

ما هو قمر الشام؟

منصة دردشة عربية متقدمة مستوحاة من التراث الشامي، تحتوي على نظام رتب ملكي، غرف متعددة، رسائل خاصة، حالات يومية، بوتات ذكية (سجان، حكواتي، مسابقات، إسلاميات، سفير)، نظام سجن وحظر، إطارات أفاتار، أنماط سينمائية للأسماء، رسائل مميزة، رسام مدمج، مشغل يوتيوب مصغّر، وميزات أداء متقدمة.

الرؤية

  • منصة دردشة ملكية فاخرة بتصميم ذهبي داكن
  • RTL عربي كامل، بدون مكتبات خارجية ثقيلة (فقط Fabric.js للرسام)
  • أداء عالي مع تقليل استهلاك Firebase (Optimizers)
  • حماية أمنية متعددة الطبقات (بصمة جهاز + IP + رتب)
  • ميزات اجتماعية غنية (حالات، إعجابات، صداقات، تفاعلات)

المتطلبات التقنية

Realtime Database + Authentication (Compat v10.7.1)
🌐

4.2 البروفايل

  • اسم 35 حرف — مع فحص تفرّد كامل
  • صور متعددة: أفاتار + غلاف + خلفية + شعر
  • موسيقى — رفع (catbox → 0x0 → TG) + مشغّل مدمج
  • شعر — 700 حرف + صورة خلفية + صورة مرفقة
  • إطارات أفاتار — مع تثبيت GIF
  • توهج بروفايل — 12 لون
  • أنماط سينمائية — 40 نمط للاسم
  • UID + زر نسخ
  • آخر تواجد حقيقي + مكان التواجد

4.3 الرسائل الخاصة (PM)

  • ترتيب زمني حقيقي (value + sort)
  • لا إشعارات على رسائلي
  • منشن مخفي (@ مخفي + إشعار واحد + صوت مرة واحدة)
  • حفظ المحذوفات (نص + صورة + صوت)
  • حذف الكل — نقل إلى شريط الأزرار
  • ردود + تفاعلات + تعديل
  • إبلاغ + استدعاء السجان
  • مراقبة الملك (PmMonitor)

4.5 السجان الذكي (Guardian)

  • كشف ذكي: تكرار + تطويل + حروف بديلة (50+ بديل عربي)
  • حذف التكرار 2+
  • استيراد قائمة عربية جاهزة (LDNOOBW)
  • Whitelist لتجنب false positives
  • نقل المخالفين للسجن فوراً + إعادة لآخر غرفة
  • عقوبات تصاعدية (2 → 4 → 8 → 15 دقيقة)
  • 3 سجنات → طرد دائم + بصمة + IP

4.6 البصمة والحماية

  • بصمة متقدمة: Canvas + WebGL + Audio + Fonts + Battery + Media + UA + Screen + Timezone + hardwareConcurrency → djb2 hash 32 حرف
  • IP من ipwho.is
  • منع الحسابات المكرّرة من نفس الجهاز/IP
  • حظر + إشعار الملك تلقائياً
  • شارة الزائر/العضو في كل مكان
  • منع الزائر من كل شي إلا العام + تبديل الغرف

10.4 دالة can()

function can(user, permission) {
    if (!user || !user.rank) return false;

    // 1. customPermissions تتفوق (تضيف فوق الافتراضي)
    if (user.customPermissions && user.customPermissions[permission] === true) {
        return true;
    }

    // 2. الملكة = Master Owner كقاعدة
    if (user.rank === 'Queen') {
        const mo = RANKS['Master Owner'];
        return mo[permission] === true;
    }

    // 3. باقي الرتب كالمعتاد
    const rank = getRank(user.rank);
    const value = rank[permission];
    if (typeof value === 'boolean') return value;
    if (typeof value === 'string') return true;
    return false;
}

  5. انشر الملفات على الرئيسي
  6. أعد تسجيل الملك عبر config/king_uid

11.3 Service Worker

💡 تذكير: sw.js محذوف من التجريبي. عند الاستبدال النهائي للرئيسي → أرجع sw.js الأصلي للرئيسي أو احذف الـ registration من index.html.

🔧 13. حل المشاكل

🔴 Firebase permission_denied

السبب: القواعد لا تسمح بهذه العملية.

الحل:

  • تحقق من رتبتك (قد تحتاج مستوى أعلى)
  • افتح Firebase Console → Rules → اختبر القاعدة
  • راجع قسم Firebase Rules
🔴 البصمة/الجهاز لا تعمل (device-guard)

السبب: فشل جلب IP أو بناء البصمة.

الحل:

  • افتح Console → ابحث عن "🛡️ DeviceGuard"
  • تحقق من اتصال الإنترنت (يحتاج ipwho.is)
  • أو: async Battery/Audio قد يأخذ وقت (طبيعي)
🔴 الفيديو لا يعمل في الحالات

السبب: Telegram Bot Token منتهي أو الشبكة بطيئة.

الحل:

  • جرّب فيديو أصغر (< 20MB)
  • تحقق من uploader.js ← TG_TOKEN
  • انتظر 30 ثانية (قد يكون بطيء على شبكة ضعيفة)
🔴 GIF يتجمد في الإطارات

السبب: animations transform/filter على الصور المتحركة.

الحل:

  • تأكد من رفع frames-engine.css v3
  • افتح Console → ابحث عن .qf-animated
  • إذا GIF ما زال يتجمد على iOS → هذا قيد المتصفح
🔴 الرسائل الخاصة لا تُرتَّب

السبب: loadPrivateMessages القديم.

الحل: تأكد من رفع pm-enhanced.js v10.

🔴 يوتيوب لا يبحث

السبب: Piped/Invidious APIs معطّلة مؤقتاً.

الحل:

  • نظام fallback تلقائي (4 Piped + 4 Invidious) — جرّب مرة أخرى بعد دقيقة
  • أو الصق رابط YouTube مباشرة (يعمل دائماً)
🔴 الرسام لا يفتح (Fabric.js)

السبب: CDN بطيء أو محجوب.

الحل:

  • افتح Console → ابحث عن "Fabric.js"
  • جرّب بعد إعادة تحميل الصفحة
  • تأكد من وصول cdnjs.cloudflare.com
🔴 الشريط العائم لا يرافق الكيبورد

السبب: floating-toolbar-v2.js غير محمّل.

الحل:

  • تأكد أنه موجود في index.html
  • يجب أن يكون آخر ملف defer
  • افتح Console → ابحث عن "FloatingToolbar v2"
🔴 الشات لا يفتح بعد الدخول

السبب: initChat لم يُستدعَ أو حدث خطأ.

الحل:

  • افتح Console → ابحث عن "❌" أو "Error"
  • تأكد من room-picker.js — قد ينتظر اختيار غرفة
  • جرّب localStorage.clear() ثم أعد التحميل
🔴 الشات بطيء (King 20MB)

السبب: musicURL كبير (base64).

الحل: auth.js v8.8 يحوي light-fetch (2KB بدل 20MB). تأكد من رفعه.

🔴 القوائم الجانبية لا تظهر فوق الشريطين

الحل: تأكد من رفع chat-ui.css وربطه في index.html.

🔴 علامة "@" في المنشن تظهر (يجب أن تكون مخفية)

الحل: تأكد من رفع chat.js v3.18 (أو v3.17 على الأقل).
